# Aviso sobre a arte

Este projeto usa arte pixelada original e uma interface própria inspirada em RPGs clássicos de captura e batalha de criaturas.

- Não contém sprites, músicas, nomes de criaturas ou cenários oficiais de Pokémon.
- `Octocat` e a identidade visual do GitHub pertencem ao GitHub.
- O projeto não é afiliado, patrocinado ou aprovado pela Nintendo, The Pokémon Company ou GitHub.
